# YourWarframe
A Warframe event tracker made by Yumia for personal use and coding practice.
## Features
### Specialised Fissure Alerts
- Receive updates about Omnia Survival and Void Cascade Fissures
### Archon Hunt Tracking
- Receive updates and reminders about the current active archon-hunt (and its corresponding shard)
### Nightwave Tracking
- Receive updated about ongoing nightwave challenges (including earnable standing)
